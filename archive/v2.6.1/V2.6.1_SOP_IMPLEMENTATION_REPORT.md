## 5. Exact Lifecycle State Contract

Legal states remain SOP-derived from V2.6:

- Media Need: `HIGH PRIORITY`, `RECOMMENDED`, `OPTIONAL`, `NO MEDIA NEEDED`
- Candidate: `NOT FOUND`, `FOUND`, `SEMANTICALLY VERIFIED`
- Rights: `VERIFIED`, `UNRESOLVED`, `HUMAN RISK ACCEPTED`, `NOT REQUIRED FOR EMBED`
- Human Decision: `APPROVED`, `WAIVED`, `REVISE`, `BLOCK`, `PENDING`
- Integration: `NOT INTEGRATED`, `INTEGRATED`, `FALLBACK ONLY`
- Visual Gate: `PENDING`, `PASS`, `REVISE`, `BLOCK`

Starter projection is exact-state-combination based and ordered by explicit precedence. Unknown states or unsupported combinations are malformed input and must fail closed. No new lifecycle enum states were invented.

Readiness mapping added:

- `NO MEDIA NEEDED` branches first and evaluates in this order: conflict/revise/block, pending Human/visual review, resolved no-media, unsupported.
- Resolved no-media readiness requires positive `need_rationale`, `candidate_state: NOT FOUND`, `rights_state: NOT REQUIRED FOR EMBED`, `human_decision: APPROVED` or `WAIVED`, `integration_state: NOT INTEGRATED`, and `visual_gate_state: PASS`.
- In the `NO MEDIA NEEDED` branch, `NOT FOUND` and `NOT INTEGRATED` are compatible with resolved no-media readiness and are not treated as media-unresolved by themselves.
- Media-needed rows (`HIGH PRIORITY`, `RECOMMENDED`, `OPTIONAL`) evaluate in this order: explicit Human/visual `REVISE` or `BLOCK`, Human `WAIVED` / reclassification, Human `APPROVED` normal integrated media, pending Human/visual review, `FALLBACK ONLY` without waiver, unsupported.
- Normal approved integrated readiness requires `candidate_state: SEMANTICALLY VERIFIED`, accepted rights state, `human_decision: APPROVED`, `integration_state: INTEGRATED`, and `visual_gate_state: PASS`.
- Human-approved waiver/reclassification readiness requires `human_decision: WAIVED`, `visual_gate_state: PASS`, exact allowed candidate/rights/integration debt states, and non-empty `notes` or `owner_or_defer_reason` explaining waiver/reclassification/debt.
- `FALLBACK ONLY` is not resolved by itself. If it is part of the ordered Human-approved waiver/reclassification path, that path applies; otherwise it projects as fallback-only readiness evidence with severity from `media_need`.
- Example A maps to one outcome: `NO MEDIA NEEDED` conflict/revise/block, because `rights_state: UNRESOLVED` is evaluated before pending Human/visual review.
- Example B maps to one outcome: Human-approved waiver/reclassification, because explicit `REVISE/BLOCK` is absent and `WAIVED` is evaluated before `FALLBACK ONLY` and unsupported rules.

## 6. pageId_or_route Resolution Rule

`pageId_or_route` must resolve against Runtime Page Inventory:

- exactly one valid `pageId` or `route` match required;
- zero matches fail validation;
- ambiguous/multiple matches fail validation;
- media table cannot create page identities;
- Runtime Page Inventory remains publication SSOT;
- leading `/` is only a route-like parsing hint.
