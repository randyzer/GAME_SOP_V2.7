# Keyword Research Template

## Purpose

Turn raw searches, entities, player questions, competitor evidence, and community language into structured SEO opportunities.

Keyword research prioritizes and names demand. It does not replace entity/player-journey/competitive-coverage planning.

This artifact follows `NEW_GAME_SITE_SOP_v2.6.2.md`.

## Evidence Limits

Record:

- discovery surfaces checked;
- available keyword tools;
- reliable volume/trend/difficulty if actually available;
- inaccessible surfaces.

Do not invent metrics.

## Target Mapping

Every useful cluster maps to:

- existing target;
- proposed target;
- partial target;
- defer/no page.

## Competitive Coverage Interaction

A keyword with weak/no volume data can still justify coverage if:

- the game system is structurally important;
- competitors prominently cover the intent;
- player questions recur;
- the page has strong internal-link/wiki value.

Do not let missing keyword-volume data automatically eliminate a major wiki family.

## Decision Rules

- avoid duplicate intent;
- prefer Hub when many long-tails overlap;
- split only for distinct intent;
- use partial page when the intent is clear but detailed data is incomplete;
- material page-family changes require human review.

## Deferred Intents

For each deferred important intent record:

- why;
- whether partial coverage is possible;
- competitor coverage;
- missing evidence;
- revisit trigger.
